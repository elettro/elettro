Key Findings
Live Liquid template error on homepage High

The rendered homepage throws a visible template error ("Could not find asset snippets/icon-search.liquid") in place of the site search icon — a broken component actively serving to users and crawlers.

Fix in rebuild
Fragmented domain architecture High

Core functions are split across four separate domains/subdomains — springfootwear.com, rep.springfootwear.com (catalogs, wholesale login), springfootwear.myshopify.com (store locator), and a third-party PrismHR careers portal — diluting entity consistency for AI answer engines.

Fix in rebuild
Generic title & meta description Medium

Homepage title and meta description both read simply "Spring Footwear Corporation" / "Official Corporate Site" — no target keywords, category terms, or value proposition for search or AI snippets.

Fix in rebuild
Mismatched navigation links Medium

Several nav items resolve to the wrong destination — "L'Artiste Kids" links to an /our-values page, "Essential Shoe Care Kit" links to the store locator — weakening crawl paths and user trust signals.

Fix in rebuild
No llms.txt or visible structured data High

No llms.txt file was found, and JSON-LD/schema.org markup could not be confirmed via automated inspection — flagged for manual verification via Google's Rich Results Test and browser source view.

Fix in rebuild
No content hub / blog presence Medium

The site is catalog-only with no editorial or educational content layer, limiting topical depth for organic rankings and reducing the surface area AI engines can cite.

Fix in rebuild
Incomplete social metadata Low

Twitter card metadata includes an empty twitter:site handle ("@"), a minor but easily-fixed signal gap in social/AI preview rendering.

Fix in rebuild
Responsive foundation in place Low

Viewport meta, canonical tag, and Open Graph basics are correctly implemented — a workable baseline the rebuild can build on rather than replace.
