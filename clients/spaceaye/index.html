02

Current-State Findings

Manual audit findings behind the scores above, split by discipline.

SEO — 62/100

Search Engine Optimization

Working in its favor

  • Full Open Graph + Twitter Card set — clean social previews
  • Descriptive, keyword-bearing title & meta description
  • Canonical tags correctly implemented
  • Clean, folder-based URL taxonomy by sector
  • Active blog channel exists as a content engine

Holding it back

  • H1 is a tagline, not a keyword target — the single highest-weight on-page tag is underused
  • Inconsistent alt text — several images carry raw filenames instead of descriptions
  • Homepage copy is thin relative to competitive geospatial SaaS pages
  • No structured data (Organization / Product schema) detected
  • Repeated text blocks in source (carousel artifact) read as duplicate content to crawlers
AIO — 58/100

AI / Answer-Engine Optimization

Working in its favor

  • Entity ("Space Aye = satellite imagery + IoT data") stated clearly, early
  • Real third-party press citations embedded — strong E-E-A-T fuel
  • Named, credentialed testimonial an LLM can attribute confidently
  • Short, quotable brand claims ("AI classifies. Only Space Aye identifies.")

Holding it back

  • No FAQ / Q&A-formatted content — the format answer engines favor most
  • No JSON-LD schema — the clearest machine-readable trust signal, entirely absent
  • Shallow explanatory depth outside the homepage taglines
  • No visible freshness/date signals on evergreen pages
