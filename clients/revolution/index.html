The Framework

There's no single certified "SEO/AIO score" — no search engine publishes one. This is a 100-point rubric split across four areas that map to how both traditional search and AI answer engines actually evaluate a site.

25 PTS

Technical SEO

Crawlability, page speed, Core Web Vitals, mobile experience, structured-data pipeline.

25 PTS

On-Page Content

Title tags, meta descriptions, heading structure, content depth and originality, freshness.

25 PTS

AIO Readiness

Schema.org markup (Event, LocalBusiness, FAQ), direct-answer content, entity clarity for AI engines.

25 PTS

Local / Off-Page

NAP consistency, review and citation signals, local pack strength, third-party authority.

Path to 95

Thirteen steps, in two phases. The first nine are build work — done once, in the redesign. The last four are earned, not built — they run for months after launch, and no rebuild can shortcut them. That split is the honest answer to "how do we get to 95," not a reason to skip the last phase.
